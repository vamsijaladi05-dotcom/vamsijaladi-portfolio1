Design lab

Short interactive notes on how I use colour, buttons and components. Try them.

Colour theory

Harmony comes from where hues sit on the colour wheel. Complementary colours sit opposite for strong contrast. Analogous colours sit side by side for calm. Triadic colours are evenly spaced for energy. I split a layout 60% neutral, 30% secondary and 10% accent.

Buttons

A button needs clear states so people always know what is happening: default, hover, pressed, loading and disabled. Motion confirms each change, so keep it short and eased. Try each one.

Hover: fill sweeps in
Pressed: ripple
Loading, then done
Disabled: faded

Components & variables

A component is built once and reused everywhere. Variables hold values like colour and corner radius, so changing one value updates every instance at once. This is how I build my Figma files. Change the variables and watch the component.
